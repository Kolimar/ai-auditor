# Defense preparation

A defense is won by knowing where the thesis is weakest before the examiners do.

## Steps

1. Read the abstract, the introduction and the conclusion to extract the headline claims. Write them down as a numbered list.
2. For each claim, trace it to the evidence chapter. Note the assumptions it depends on, the datasets or cases used, and the metric. Look for the places where evidence is thin.
3. Generate likely questions in four groups: motivation ("why does this matter"), method choices ("why not approach Y"), validity ("how do you know this is not an artifact of Z"), and impact ("what would change if you are wrong").
4. Draft a short answer for each, grounded in what is actually in the thesis, with pointers to the exact sections and figures. Where the honest answer is "that is a limitation", draft how to say so confidently.
5. Identify three questions that the author probably dreads and suggest how to rehearse them.
6. Close with a one-page cheat sheet of key numbers the author should know by heart.

Ask the user about the examiners' backgrounds if known, because it changes which questions are likely.
