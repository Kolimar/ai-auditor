name: store-release-notes
description: Write App Store and Play Store release notes from the commits and issues of a release.
---
Collect the user-facing changes from the commit log and closed issues. Write release notes in a friendly tone for hikers, max 500 characters for Play Store and 4000 for App Store, leading with the most noticeable improvement. Skip internal refactors. Offer two variants of the first line.
