---
name: incident-writeup
description: Write a blameless post-incident report for a security incident from a timeline and responder notes.
---
Build the report from the timeline and the notes: summary for executives, detailed timeline, root cause analysis (technical and process), what went well, what went poorly, and action items with owners. Keep it blameless. When the notes conflict on a fact, list both versions and mark the item for confirmation.
